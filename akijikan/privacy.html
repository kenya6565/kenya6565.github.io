Akijikan プライバシーポリシー

制定日: 2026年11月3日

Akijikan（以下「本ツール」）は、Google カレンダーの空き時間をクリップボードにコピーする Raycast 拡張機能です。本ツールが扱う情報と、その扱い方を説明します。

1. 取得する情報

  • カレンダーの空き時間情報: サインインした Google アカウントのカレンダーで「予定あり」になっている時間帯（Google Calendar API の freeBusy。スコープ https://www.googleapis.com/auth/calendar.freebusy）。予定のタイトル・参加者・場所・説明は取得しません。
  • メールアドレス: サインインしたアカウントのメールアドレス（スコープ openid・email）。
  • 認証トークン: Google が発行するアクセストークンとリフレッシュトークン。

2. 利用目的

  • 空き時間情報は、登録したアカウントがすべて空いている時間を計算し、その結果を利用者のクリップボードにコピーするためだけに使います。
  • メールアドレスは、登録済みアカウントの一覧表示、同じアカウントの重複登録の防止、空き時間情報の問い合わせ先の指定に使います。
  • 広告、分析、機械学習の学習など、上記以外の目的には使いません。

3. 保存場所と第三者提供

  • 本ツールは利用者の Mac 上の Raycast の中だけで動きます。作者はサーバーを運用しておらず、取得した情報が作者や第三者に送られることはありません。
  • 空き時間情報そのものは保存しません（計算結果の空き日程がクリップボードにコピーされます）。メールアドレスは Raycast のローカルストレージに、認証トークンは Raycast が管理する保存領域に、それぞれ利用者の Mac 内で保存されます。
  • 通信先は Google のサーバー（認証と Google Calendar API）だけです。

4. Google API Services User Data Policy への準拠

本ツールが Google API から受け取った情報の使用と他のアプリへの転送は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

5. 削除とアクセスの取り消し

  • Raycast の「Manage Accounts」でアカウントを削除すると、そのアカウントのメールアドレスと認証トークンが Mac から削除されます。
  • Google 側で本ツールへのアクセス許可を取り消すには、Google アカウントのサードパーティ製アプリとサービスの一覧から「Akijikan」を削除してください。

6. 変更

このポリシーを変更する場合は、このページを更新し、制定日の下に改定日を記載します。

7. 問い合わせ
